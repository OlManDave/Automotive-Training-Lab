To publish:
1. Create a PUBLIC GitHub repository called automotive-training-lab.
2. Upload the CONTENTS of this ZIP to repository root.
3. Settings > Pages > Build and deployment > Deploy from a branch.
4. Select main and /(root), then Save.
5. Visit https://YOUR-USERNAME.github.io/automotive-training-lab/

This preserves the original master-cylinder HTML and behaviour.
